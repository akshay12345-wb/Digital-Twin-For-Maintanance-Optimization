# Digital-Twin-For-Maintanance-Optimization

This project is a Digital Twin-based predictive maintenance system designed to monitor industrial machines and predict potential failures using Machine Learning.

The system analyzes sensor data such as temperature, vibration, pressure, and RPM to identify machine health conditions and classify machines as Healthy, Warning, or Critical.

It uses a Random Forest model and multiple intelligent agents for machine monitoring, failure prediction, maintenance scheduling, and notifications. An interactive Streamlit dashboard displays machine status, health scores, predictions, and maintenance recommendations.
